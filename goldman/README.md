# ProofGate — start here

**Current, 4 October 2026:** ProofGate Blind Workbench is the primary demonstration.
Actual AI composes approved public operations; the company-controlled host applies
private synthetic contracts and decision rules locally. A useful negotiation brief
changes when private facts change, without new provider attempts. The permitted
internal save has independent exact read-back. The inherited release assistant
remains supporting evidence.

**Mission:** Let organizations give AI agents useful autonomy while retaining
enforceable control over data, actions and spending.

**Vision:** ProofGate is a lightweight, configurable hybrid control layer:
developers integrate it easily, security teams inspect decisions, and judges
can change policies and verify real outcomes in a polished workbench.

**Primary scene ambition:** AI supplies the method. The company keeps its know-how.

ProofGate is the assessed control layer. Authentication, strict schemas,
deterministic and actual semantic inspection, mutable policies/model allowlists,
source/destination/privacy controls, shared finite allowance, independent effects,
automated tests, sanitized audit/export and measured telemetry remain real
obligations. No production-security or universal protection claim is made.
